# Toolkit Scanner

Toolkit Scanner 是一款多功能的 Android 应用程序，旨在为用户提供便捷的日常办公与图像处理工具。

## 功能特性

- **图像扫描**：将拍摄的照片快速转换为高质量的电子文档，并支持导出合并的多页 PDF。
- **试卷擦除**：一键去除试卷照片中的手写笔迹，自动还原空白试卷，便于重新打印练习。
- **全能 PDF 预览**：应用内嵌沉浸式 A4 PDF 预览器，支持多页快速滑动。
- **多端分享与打印**：一键保存生成的电子文档至手机公共目录、原生地唤起微信等系统分享、甚至可以直接连接打印机打印文档。

## 技术栈

- 语言：Kotlin
- UI 框架：Jetpack Compose
- 架构：现代 Android 开发架构

## 开发环境

- Android Studio 
- Gradle

## 安装与运行

克隆本仓库到本地，使用 Android Studio 打开项目并同步 Gradle 即可运行。
